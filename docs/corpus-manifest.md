# The documents

Every source file each corpus is built from, with the title extracted at ingest and
the number of passages it contributes. **The files themselves are not in this
repository.** See [`ATTRIBUTION.md`](../ATTRIBUTION.md) for why, and for how to rebuild each
set from its original source.

Generated by `src/build_corpus_manifest.py` from the built indexes, so it lists what
the retriever can actually see rather than what happens to be in a folder.
