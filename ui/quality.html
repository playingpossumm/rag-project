What each mechanism is worth

Each row adds one mechanism to the row above it, scored end to end at k=5 on the same questions. The cross-encoder is the largest single gain and the diversity cap is the only row that trades one metric for another — it gives up ranking to return more of the documents that answer the question, which is the trade this system chose.

The same pipeline on three corpora shipped configuration

The pipeline was tuned on the ML papers. Two further corpora were built to find out how much of it is a property of the system and how much of the documents it was tuned on.

Source recall is not comparable across these three as a raw number. It is normalised by min(|gold|, 5), and the corpora do not agree on how many documents answer a question — so the finance corpus is scored against a divisor larger than the ML one and has to return more documents in the same five slots to score the same.

The abstention threshold does not transfer the finding that matters

Every question scored by the cross-encoder, plotted on one axis. Filled marks are questions the corpus can answer; hollow rings are adversarial questions whose answer is deliberately absent. The gate refuses everything left of its cut point, so the ideal threshold sits in the gap between the two populations — and that gap is in a different place on every corpus.

Moving each corpus to its own cut point recovers answers at no adversarial cost whatever — the same number of planted questions is still caught in every case. That is the rare case of a strictly dominant change, and it is only visible because the corpora were measured separately.

What every cut point would cost

Counted in cases, not rates. Rates are the wrong unit here: the two populations are different sizes, so subtracting one rate from the other quietly values a single adversarial catch at several answerable questions thrown away.

This system does its job and is measured honestly about where it does not. It is not competitive with NotebookLM or Glean, which is not what it is for — it exists so every stage of retrieval can be watched and every default can be made to earn its place against a number.
