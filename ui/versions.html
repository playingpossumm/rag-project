Hero diagram — every version

All four versions the drawing has been through, from one trace, each rendered by the code from the commit that produced it. The slider and the Play button drive every canvas at once, so the same moment of the same run is being compared.

1 — Original

before option C

Deep plates, every stage the same matrix of cells, stages assembled in sequence rather than being present from the first frame. This is the version you said you preferred over the first attempt at C.

2 — Option C, first attempt

shapes on top of the old plates

The per-stage treatments were added, but the plates stayed four to six sheets deep with a lattice on every sheet, so the box drowned them. This is the one that looked worse rather than better.

3 — Option C, thin plates

one sheet per stage

One outline per stage, no side edges, no repeated lattice. Dense is a scatter, BM25 is bands, the cap is a grate, the answer is balls. Still had two faults: one line per sampled mark out of the index, and refused passages stopping in mid-air.

4 — Current

version 3 plus the two fixes

A line for every surviving passage out of the index, and the cap's refusals drawn on its own face in red instead of hanging in the air before it.
